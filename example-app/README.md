# @capgo/capacitor-live-activities

Minimal Capacitor demo linked to the local plugin via `file:..`.

## Actions

- **Refresh** – Check Live Activities support and list active activities.
- **Plugin version** – Read the native plugin version.

## Getting started

```bash
bun install
bun run start
```

Add native shells with `bunx cap add ios` or `bunx cap add android` from this folder.
